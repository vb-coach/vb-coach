# vb_coach 总体规划

研究排球二传出球的物理参数（位置 / 速度 / 角度 / 高度 / 旋转）如何决定攻手"立得住 / 球头"的感受，并给业余球员可量化的建议。

## 项目原则

- **两阶段拆分**：A = 正向（释放状态 → 轨迹 → 品质）；B = 逆向（身体动作 → 释放状态），推迟
- **业余优先**：攻手助跑摸高典型 260-290 cm（男）/ 230-260 cm（女）；高球 / 半高 / 平拉开是核心战术
- **按战术分层**：每种球种"好球"的定义不同（顶点击球 vs 下降段击球）
- **亚临界气动**：球速 4-8 m/s，Re ≈ 50k-120k，用 Cd ≈ 0.45 光滑球模型，忽略飘动效应（Darbois Texier 2016 等支持）

## 技术栈

Python 3.11+ / numpy / scipy / matplotlib / pytest / uv。Phase A6 可视化阶段加入 Plotly 或 Three.js。

## Phase A0：轨迹引擎核心

**目标**：`ReleaseState`（3D 位置 / 速度 / 旋转向量）→ `Trajectory`（时序的位置 / 速度 / 旋转）。

**模型**：`F = mg + F_drag + F_Magnus`
- 重力：`-9.81 ẑ`
- 阻力：`-(1/2)ρ|v|²·A·Cd·v̂`，`Cd = 0.45`（常数，文献支持）
- Magnus：`(1/2)ρ|v|²·A·Cl(S)·(ω̂ × v̂)`，`Cl` 线性到 0.2 饱和

**产出**：`src/vb_coach/` 库 + 4号位高球示例。

**详细实施**：[superpowers/plans/2026-05-10-phase-a0-trajectory-engine.md](superpowers/plans/2026-05-10-phase-a0-trajectory-engine.md)（9 个任务，TDD，约 44 个测试，frequent commits）

## Phase A1：4号位攻击

**目标**：模拟 3 种球种 + 各自的"好球"度量函数。

| 球种 | apex 高度 | 飞行时间 | 击球时机 | 品质代理 |
|---|---|---|---|---|
| 高球 | 4.5-6.0 m | 1.5-2.0 s | 下降段 | 下降角恒定性 / `v_z` ∈ [-5,-3] m/s / 横向漂移 < 20 cm |
| 半高 | 3.0-4.0 m | 1.0-1.4 s | 下降段早期 | 同上，窗口更紧 |
| 平拉开 | 网上 1-1.5 m（扁平）| 0.5-0.8 s | 接近顶点 | 高度恒定段的水平距离 / 横向速度恒定 / 旋转最小 |

**新增模块**：
- 击球窗口几何（攻手助跑 + 跳跃 + 手臂可及的 3D 体积）
- 品质评分函数：对每种球种返回 0-1 标量

**产出**：`src/vb_coach/attacks/position4.py`。

## Phase A3：3号位快攻

**目标**：4 种快攻 + 顶点击球的品质度量。

| 球种 | apex above release | 飞行时间 | 备注 |
|---|---|---|---|
| 近体快（A 快）| 0.5-1.0 m | 0.25-0.35 s | 攻手空中等球 |
| 背快 | 0.5-1.0 m | 0.25-0.35 s | 二传身后 |
| 背飞 | 0.5-1.0 m | 0.4-0.6 s | 攻手横移 |
| 短平 | 0.3-0.5 m | 0.4-0.5 s | 低平球 |

**品质代理**：
- 顶点附近 `|v_z| < 1 m/s` 的时长（顶点击球版"立得住"）
- 顶点位置精度（vs 攻手预期击球点）

**业余 caveat**：快球业余少见，本阶段优先级低于 A1。

**产出**：`src/vb_coach/attacks/position3.py`。

## Phase A5：攻手适配层

**双向工具**：
1. 给定 `(身高 / 站立摸高 / 助跑摸高)` → 可击中球种 + 推荐最优
2. 给定 `(攻手 + 目标球种)` → 反推二传应有的释放状态分布

**业余 reach 分布**（来自 ~30 个 VolleyTalk / narkive / Hupu 自报样本 + 中国高校招生标准 + 反推职业数据）：

| 群体 | 击球球心高度 μ (cm) | σ | 模拟范围 |
|---|---|---|---|
| 业余男（普通）| 280 | 12 | 256-304 |
| 业余男（规律训练）| 295 | 12 | 271-319 |
| 业余男（校队背景）| 315 | 10 | 295-335 |
| 业余女（普通）| 240 | 12 | 216-264 |
| 业余女（规律训练）| 260 | 10 | 240-280 |
| 业余女（校队背景）| 285 | 10 | 265-305 |

**关键约定**：球心高度 ≈ 助跑摸高 − 10-15 cm（业余技术差时可达 20-25 cm）。

**网上余量**：业余男 ~70% 能达网上 30 cm，~40% 达网上 50 cm；业余女 ~45% 达网上 30 cm。详细分布见 [memory reference](../docs/PLAN.md)。

**产出**：`src/vb_coach/attacker.py` + 推荐器 CLI。

**数据 caveat**：自报上浮偏差 5-15 cm；中文数据 sample 不足，需后续手动从 Zhihu 大帖补充。

## 关键概念约定

- **立得住** ≠ 单一指标。顶点击球（快球）用顶点速度模和时长；下降段击球（高球 / 半高）用下降角恒定性和横向漂移。
- **球头** ≈ 旋转轴相对攻手视线的角度 + 旋转率（低旋转的"明确前缘"由 Craig & Bootsma 2015 等感知文献支持）。
- **击球时刻 vs apex**：高球类在飞行时间约 60-70% 时刻击球；快球类在 apex 击球。
- **坐标系**：原点在网中心地面，x 沿网，y 跨网（正向 = team A），z 向上。
